# 使用说明

整理自仓库根目录的 `使用说明.txt`。

## 运行

- 双击 `gui.exe`，保证它与所有 `.dat` 文件、`map.jpg` 在同一文件夹。
- 重新编译：Visual Studio + [EasyX](https://easyx.cn)，以 UTF-8（带 BOM）编译 `gui.cpp`，链接 `EasyXw.lib`。
- 源码与数据文件都用 UTF-8；用其他编码重新保存会导致中文乱码。

## 操作

| 功能 | 操作 |
| --- | --- |
| 路线规划 | 第一次点击地点 = 出发地（绿标），第二次 = 目的地（红标）；选 `1` 骑车 / `2` 驾车 / `3` 电动车 / `4` 步行（地铁口之间自动 `5` 地铁）；路线红色高亮，弹窗显示距离、用时、预计到达时刻 |
| 地点搜索 | 左上角「搜索」，输入部分关键词即可匹配地点或美食；结果可设为出发地 / 目的地 / 探索；登录后输入 `0` 查看历史导航地点 |
| 地点探索 | 查看类型、热度、可直达地点；探索荷园 / 松园 / 菊园 / 柳园可挑美食导航；探索图书馆进入图书系统 |
| 登录注册 | 右上角「登录」；注册需学号（4~12 位数字）+ 密码（至少 4 位，输两遍）；登录状态本次运行内有效 |
| 收藏 | 登录后「收藏 / 收藏列表 / 取消收藏」，按学号存储 |
| 美食导航 | 「美食」按园区浏览 49 条，选定后输入出发地自动导航 |
| 图书管理 | 查询 / 借书（自定义应还日期 0~30 天）/ 还书 / 我的借阅 / 7 大分类浏览，共 70 本 |
| 地铁出行 | 4 个地铁口（郑大科技园 C/B 口、河南工业大学 E 口、郑州大学 C 口），5 段线路、60 km/h |

快捷键：`F1` 路线质量检测（穿楼 / 断头 / 孤立点）｜`F2` 问题反馈｜鼠标拖拽平移地图｜右键清空起终点｜`ESC` 退出。

## 数据文件

| 文件 | 内容 | 格式（`|` 分隔） |
| --- | --- | --- |
| `places.dat` | 28 个地点 | 编号 \| 名称 \| 类型 \| 热度 |
| `coords.dat` | 地点坐标标定 | 编号 \| x \| y |
| `junctions.dat` | 路口坐标标定 | 编号 \| x \| y |
| `place_junctions.dat` | 地点 ↔ 最近路口 | 地点编号 \| x \| y \| x \| y \| … |
| `roads.dat` | 地点直达关系 | 起点 \| 终点 \| 距离 \| 耗时 |
| `roads_custom.dat` | 道路折线 | 起点 \| 终点 \| x \| y \| … |
| `books.dat` | 图书 70 本 | 书号 \| 书名 \| 作者 \| 出版社 \| 总库存 \| 可借数 \| 馆藏位置 \| 分类 |
| `foods.dat` | 美食 49 条 | 园区 \| 名称 \| 价格 \| 特色 |

以下文件**运行时自动生成**，属个人数据，已排除出版本控制：

`users.dat`（学号 \| 口令）、`favorites.dat`、`search_history.dat`、`nav_history.dat`、`borrows.dat`、`feedback.txt`。

## 写回策略

用户数据修改采用「临时文件重写」：先写 `.tmp`，再 rename 覆盖原文件，避免中途失败写坏数据。读取时兼容早期单用户格式（无学号字段的旧行归属当前用户）。

## 常见问题

- **中文乱码**：源文件需 UTF-8（带 BOM），程序内中文用宽字符 `L"..."`，EasyX 用宽字符绘制函数。
- **地点点不中**：命中半径按窗口缩放比例换算，窗口缩小时可拖拽平移放大视图。
- **功能不可用**：确认 `map.jpg` 与对应 `.dat` 存在；删除它们会导致相关功能失效。
- **弹窗空白**：批量绘制模式下直接调 `MessageBox` 会覆盖缓冲区，程序已用 `popupMsg` / `popupYesNo` / `popupInput` 封装，内部先 `EndBatchDraw`。
