校园地图导航系统 —— 使用说明
===============================

一、文件清单
  gui.cpp        源程序（UTF-8 编码，EasyX 图形版，约 2100 行）
  gui.exe        已编译好的可执行程序（双击运行，无需安装）
  map.jpg        校园地图背景图（实景卫星图）
  places.dat     地点数据（28 个地点：校门、教学区、宿舍、地标、运动、医疗、地铁口等）
  coords.dat     地点坐标（标定数据）
  junctions.dat  路口坐标（标定数据）
  place_junctions.dat  地点与最近路口的关联数据
  roads.dat      地点直达关系
  roads_custom.dat     道路折线数据（沿真实道路标定）
  books.dat      图书数据（70 本，图书馆系统使用）
  foods.dat      美食数据（49 条，美食导航使用）
  课程设计报告-校园地图导航.docx   课程设计报告（含完整源码、运行截图、测试用例）

  （users.dat / favorites.dat / search_history.dat / nav_history.dat /
    borrows.dat / feedback.txt 在首次使用对应功能时自动生成）

二、如何运行
  双击 gui.exe 即可运行（请确保与数据文件放在同一文件夹）。
  如需重新编译：Visual Studio + EasyX 图形库（https://easyx.cn），
  以 UTF-8（带 BOM）编码编译 gui.cpp 即可。

三、操作说明
  1. 路线规划：点击地图上的地点，第一次点击设为出发地（绿色标记），
     第二次点击设为目的地（红色标记），选择出行方式
     （1 骑自行车 / 2 驾车 / 3 电动车 / 4 步行；地铁口之间自动使用 5 地铁），
     最快路线以红色高亮显示，并弹窗提示距离、用时与预计到达时刻；
  2. 地点搜索：左上角"搜索"按钮，输入关键词（支持部分关键字）搜索地点或美食，
     选择后可设为出发地 / 目的地 / 探索；登录后输入 0 可查看历史导航地点；
  3. 地点探索：搜索地点后选"探索"，可查看地点类型、热度与可直达地点；
     探索荷园 / 松园 / 菊园 / 柳园可挑选美食导航；探索图书馆可进入图书管理系统；
  4. 登录注册：右上角"登录"按钮，注册需学号（4~12 位数字）+ 密码（至少 4 位），
     登录后可使用收藏、搜索历史、历史导航地点等功能；
  5. 收藏管理：登录后可用"收藏 / 收藏列表 / 取消收藏"管理常用地点；
  6. 美食导航：左上角"美食"按钮按园区浏览 49 条美食，选定后输入出发地自动导航；
  7. 图书管理：图书馆系统支持查询图书、借书（自定义应还日期 0~30 天）、还书、
     我的借阅、按分类浏览（计算机 / 数学 / 物理 / 文学 / 历史 / 经济管理 / 哲学）；
  8. 地铁出行：地图上有 4 个地铁口（郑大科技园C口/B口、河南工业大学E口、郑州大学C口），
     从校门步行可达，地铁口之间自动规划地铁线路（5 段，60 km/h）；
  9. 辅助功能：F1 路线质量检测（穿楼路段 / 断头路口 / 孤立地点），
     F2 问题反馈，鼠标拖拽平移地图，右键清空起终点选择，ESC 退出程序。

四、注意事项
  · 程序、数据文件均使用 UTF-8 编码，请勿用其他编码重新保存；
  · 删除 map.jpg / places.dat / roads.dat / roads_custom.dat / books.dat / foods.dat
    会导致对应功能无法使用；
  · 报告附录含完整源码与运行界面截图，测试用例与结果见报告第四章。
